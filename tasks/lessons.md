## 2026-11-11 — README accuracy review

**Correction:** I reported 4 README scores as wrong. On recheck, 2 were correct and 1 was only overstated. I had read
ambiguous sentences one way and only checked that one pair.

- "unrelated *Software Engineer* (0.34) scores higher": I checked CRO ↔ Software Engineer (0.22). The README means
  Software Engineer ↔ VP of Sales, which is 0.34. The README was right.
- "VP of Marketing scores 0.84 against the same title": "the same title" means VP of Sales, and that pair is 0.84.
  The README was right.

**Rule:** before reporting a quoted number as wrong, list every pair the sentence could mean, compute each, and
call it wrong only if no reasonable reading matches. If a reading matches but the wording is unclear, report it as
"unclear wording", not "wrong".
